Binary Search Trees & Complexity Analysis

§ Invariant Definition · BST Property

For every node x: all keys in its left subtree are strictly strictly less than key(x), and all keys in its right subtree are strictly greater than key(x).

Search & Insertion Time Complexity
As a function of tree height under balanced partitioning
T(n) = O(log n)
bst_search.cpp C++20 std::optional 
Node* search(Node* root, int key) {
  if (!root || root->key == key)
    return root;
  if (root->key < key)
    return search(root->right, key);
  return search(root->left, key);
}
