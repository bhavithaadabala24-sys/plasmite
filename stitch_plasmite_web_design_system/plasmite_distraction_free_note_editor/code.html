§ 01.0 // Invariants

A binary search tree maintains a strict ordering invariant across all internal nodes, enabling logarithmic lookups, insertions, and deletions under balanced conditions. The architectural invariant guarantees that for every vertex u, all values accommodated within the left sub-arborescence strictly satisfy key(v) < key(u), while symmetric descendants to the right satisfy key(w) > key(u).

Unlike unconstrained binary heaps, which merely ensure immediate parent-child priority dominance, the BST establishes a globally continuous projective ordering. Traversing this topography via symmetric in-order progression reproduces an intrinsically sorted, monotonically non-decreasing linear sequence without ancillary sorting passes.

Fundamental Definition bookmark

“A Binary Search Tree is a node-based binary tree data structure where the left subtree of any given node contains only keys strictly less than the node’s key, and the right subtree contains only keys strictly greater. Both left and right subtrees must independently qualify as binary search trees.”

§ 02.0 // Implementation Specimen

Below is the minimal recursive formulation for lookup and construction. Notice that tail recursion on search paths mirrors pointer dereferencing across an unrolled singly-linked chain:

C++20 binary_search_tree.hpp 
// Definition of Node structure
struct Node {
    int key;
    Node *left, *right;
    Node(int val) : key(val), left(nullptr), right(nullptr) {}
};

// Logarithmic tail-recursive search
bool search(Node* root, int target) {
    if (!root || root->key == target) 
        return root != nullptr;
        
    if (target < root->key) 
        return search(root->left, target);
        
    return search(root->right, target);
}

Viva Question: Why does a degenerate binary search tree degrade to O(n) complexity?

Examiner's Verified Model Answer

When elements are inserted in strict sorted or reverse-sorted order without balancing rotations (such as AVL or Red-Black mechanisms), each parent node possesses strictly one child. The tree topology collapses into a singly linked list, transforming binary divide-and-conquer into linear traversal with O(n) depth. Consequently, search, insertion, and deletion degenerate from logarithmic efficiency down to worst-case linear time.
