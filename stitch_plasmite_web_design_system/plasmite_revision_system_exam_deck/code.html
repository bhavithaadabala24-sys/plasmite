Operating Systems · Unit 3: Deadlocks
★ High Yield Exam Topic

Banker's Algorithm & Safe State Verification

Deadlock avoidance algorithm that simulates resource allocation against known maximum declarations. Evaluates if safely satisfying upcoming demand states leaves at least one execution sequence without deadlock.

Vector Arithmetic & Matrix Constraints Complexity: O(m × n²)
Need[i, j] = Max[i, j] - Allocation[i, j]
Condition: Finish[i] == false && Work >= Need[i]  →  Work = Work + Allocation[i]
info Key Invariant: Safety state exists if all processes can terminate without circular wait conditions.

Database Systems · Unit 3: Relational Design
Dependency Preservation

Boyce-Codd Normal Form (BCNF) Lossless Decomposition

Strict normal form strictly eliminating all redundancy arising from functional dependencies. Guarantees lossless-join property though dependency preservation is not universally ensured.

Integrity Criterion FD Violation Rule
R in BCNF iff for every non-trivial FD X → Y, X is a superkey of R.
Decomposition: Replace R by (R - Y) and (X ∪ Y) when X is not a superkey.
