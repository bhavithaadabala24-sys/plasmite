01. Aim & Requirements

Theory & Environment

To formulate, simulate, and verify the decentralized Distance Vector Routing (DVR) protocol utilizing the iterative, asynchronous Bellman-Ford shortest-path algorithm across an arbitrary network topology. The objective entails modeling dynamic link advertisements, vector relaxation updates, and verifying full-graph convergence within finite iterations.

"Each network node maintains a vector of link costs to all known destinations and iteratively distributes this perspective to immediate neighbors until minimum distances stabilize."

Target Environment & Toolchain
Operating System Ubuntu 22.04 LTS (x86_64)
Compiler / Standard GCC 11.4.0 / C++20 standard
Telemetry & Packet Inspect Wireshark v4.0.2 / tcpdump

02. Algorithm & Logic

Step Execution

The protocol calculates shortest paths iteratively without requiring centralized global topology knowledge. The core relaxation follows the recurrence:

Dx(y) = minv ∈ N(x) { c(x, v) + Dv(y) }
01
Local Table Initialization Each router node x registers direct link costs c(x, v) to each immediate neighbor v. Unreachable destinations are initialized to infinity (∞), with self-cost set to 0.
02
Asynchronous Vector Broadcast Every iteration or link cost disturbance triggers an outgoing vector notification: node x transmits its current distance estimate array Dx = [Dx(y): y ∈ N] to directly connected peers.
03
Vector Relaxation & Path Selection Upon intercepting neighbor vector Dv, node x calculates candidate paths across all destinations. If traversing v reduces path cost to destination y, Dx(y) updates and next-hop is reassigned to v.
04
State Stabilization & Quiescence Cycles repeat across network nodes until no further distance modifications occur within a global iteration window, declaring complete convergence.

#include <iostream>
#include <vector>
#include <iomanip>

constexpr int INF = 999999;
constexpr int MAX_NODES = 4;

struct RoutingTable {
    int dist[MAX_NODES];
    int nextHop[MAX_NODES];
};

void updateDistanceVector(RoutingTable nodes[], const int costMatrix[MAX_NODES][MAX_NODES]) {
    bool converged = false;
    int iter = 0;

    while (!converged) {
        converged = true;
        std::cout << "\n[CYCLE " << ++iter << "] Initiating Vector Exchanges..." << std::endl;

        for (int i = 0; i < MAX_NODES; ++i) {
            for (int j = 0; j < MAX_NODES; ++j) {
                for (int k = 0; k < MAX_NODES; ++k) {
                    // Bellman-Ford Relaxation step
                    if (costMatrix[i][k] != INF && nodes[k].dist[j] != INF) {
                        int candidateCost = costMatrix[i][k] + nodes[k].dist[j];
                        if (candidateCost < nodes[i].dist[j]) {
                            nodes[i].dist[j] = candidateCost;
                            nodes[i].nextHop[j] = k;
                            converged = false;
                        }
                    }
                }
            }
        }
    }
    std::cout << "System reached steady state in " << iter << " passes." << std::endl;
}

05. Experiment Viva Questions

Oral Examination Prep

Key review checkpoints tested during practical laboratory evaluation. Click to expand full theoretical derivations and mitigation strategies.

The count-to-infinity problem manifests when an existing link between two nodes breaks or drastically increases in cost. Because updates are asynchronous and nodes rely purely on their neighbors' advertised costs without knowing intermediate path hops, routing loops develop where two or more nodes incrementally increment metric estimations towards infinity before discovering unreachability.

RFC Reference: RFC 1058 (RIP)
Mark Understood Flag for Review

Under Split Horizon, a node will not advertise a route back to the neighbor from which it learned that exact route. With Poison Reverse, rather than simply suppressing the advertisement, the node explicitly advertises that destination with an infinite cost (∞ = 16 in RIP) to the next hop. This immediately prevents the preceding neighbor from mistakenly assuming it can reroute back through this path.

Convergence Impact: Avoids 2-node cycles
Mark Understood Flag for Review

Link-State algorithms (e.g., OSPF) broadcast the complete state of individual links globally using Link State Advertisements (LSAs), permitting each router to independently compute shortest paths over an identical graph model in O(V log V) time. Conversely, Bellman-Ford relies on iterative "routing-by-rumor", where information must ripple hop-by-hop. In the presence of bad news (cost increases), relaxation can require up to O(|V| · |E|) vector exchanges to stabilize.

Complexity: O(|V|·|E|) vs O(|E| + |V|log|V|)
